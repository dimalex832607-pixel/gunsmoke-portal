# 🚀 Как запустить сайт «Дымок из ствола» — пошагово

## Что тебе нужно

Перед началом убедись, что у тебя есть:

### 1. Node.js (версия 18 или выше)

**Проверь, установлен ли Node.js:**
```bash
node --version
```

Если видишь что-то вроде `v20.10.0` — отлично! Если нет — скачай и установи:
- **Windows/Mac:** https://nodejs.org/ (выбери LTS версию)
- **Linux (Ubuntu/Debian):**
  ```bash
  curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
  sudo apt-get install -y nodejs
  ```

### 2. Git (опционально, но рекомендуется)

**Проверь:**
```bash
git --version
```

Если нет — скачай: https://git-scm.com/downloads

---

## Шаг 1: Скачай проект

### Вариант A: Если у тебя есть архив с проектом

1. Распакуй архив в удобную папку
2. Открой терминал (командную строку)
3. Перейди в папку проекта:
   ```bash
   cd путь/к/папке/gunsmoke-portal
   ```
   
   **Примеры:**
   - Windows: `cd C:\Users\ТвоёИмя\Downloads\gunsmoke-portal`
   - Mac/Linux: `cd ~/Downloads/gunsmoke-portal`

### Вариант B: Если проект на GitHub

```bash
git clone https://github.com/твой-username/gunsmoke-portal.git
cd gunsmoke-portal
```

---

## Шаг 2: Установи зависимости

В терминале, находясь в папке проекта, выполни:

```bash
npm install
```

⏳ **Подожди 1-3 минуты** — скачаются все нужные библиотеки.

Если увидишь ошибки про конфликты версий, попробуй:
```bash
npm install --legacy-peer-deps
```

---

## Шаг 3: Запусти сайт для разработки

```bash
npm run dev
```

Увидишь что-то вроде:
```
▲ Next.js 15.5.27
- Local:        http://localhost:3000
- Network:      http://192.168.1.100:3000

✓ Ready in 3.2s
```

### Шаг 4: Открой сайт в браузере

1. Открой браузер (Chrome, Firefox, Safari)
2. Введи в адресную строку: **http://localhost:3000**
3. Увидишь главную страницу с 3D револьвером! 🎉

## Шаг 5: Изучи сайт

Попробуй разные разделы:

### Главная страница (`/`)
- Увидишь 3D револьвер, который вращается
- Можешь крутить мышью (камера следует за курсором)
- Прокрути вниз — увидишь эпизод дня, факты, быстрые ссылки

### Эпизоды (`/episodes`)
- Все 635 эпизодов сериала
- Используй фильтры:
  - **Поиск:** введи название (например, "Matt")
  - **Сезон:** выбери из списка (1-20)
  - **Эпоха:** ч/б или цветной
  - **Сортировка:** по рейтингу или голосам
- Кликни на эпизод — откроется страница с деталями

### Актёры (`/cast`)
- 6 карточек основного состава
- Наведи на фото — станет цветным
- Кликни "IMDb" — откроется страница актёра

### Галерея (`/gallery`)
- 105 фото из сериала
- Кликни на фото — откроется лайтбокс
- Используй стрелки ← → или клавиши для навигации
- Esc — закрыть лайтбокс

### История (`/history`)
- Хронология 1952-2011
- 16 ключевых событий
- Прокрути вниз — увидишь таймлайн

### Отзывы (`/reviews`)
- 8 отзывов зрителей на русском
- Самый длинный — 5700 слов!

### Мой кабинет (`/me`)
- Отмечай просмотренные эпизоды
- Ставь оценки (1-10 звёзд)
- Пиши заметки
- Экспортируй/импортируй данные

## Шаг 7: Собери production версию (опционально)

Если хочешь захостить сайт в интернете:

```bash
npm run build
```

⏳ Подожди 1-2 минуты — сайт оптимизируется.

После сборки:
```bash
npm run start
```

Открой **http://localhost:3000** — увидишь оптимизированную версию.

## Шаг 8: Задеплой в интернет (опционально)

### Вариант A: Vercel (самый простой)

1. Зарегистрируйся на https://vercel.com
2. Установи Vercel CLI:
   ```bash
   npm install -g vercel
   ```
3. В папке проекта:
   ```bash
   vercel
   ```
4. Следуй инструкциям — через 1-2 минуты сайт будет в интернете!

### Вариант B: Netlify

1. Зарегистрируйся на https://netlify.com
2. Установи Netlify CLI:
   ```bash
   npm install -g netlify-cli
   ```
3. Собери сайт:
   ```bash
   npm run build
   ```
4. Задеплой:
   ```bash
   netlify deploy --prod
   ```

### Вариант C: GitHub Pages

1. Создай репозиторий на GitHub
2. Запуш код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/твой-username/gunsmoke-portal.git
   git push -u origin main
   ```
3. В настройках репозитория → Pages → выбери ветку `main` и папку `out`

## 🆘 Если что-то пошло не так

### Ошибка: `npm: command not found`
**Решение:** Node.js не установлен. Скачай с https://nodejs.org/

### Ошибка: `EACCES: permission denied`
**Решение (Linux/Mac):**
```bash
sudo chown -R $(whoami) ~/.npm
```

### Ошибка: `Port 3000 is already in use`
**Решение:** Другой сервер использует порт 3000. Запусти на другом порту:
```bash
npm run dev -- -p 3001
```
Открой **http://localhost:3001**

### Ошибка: `Module not found`
**Решение:** Удали `node_modules` и установи заново:
```bash
rm -rf node_modules package-lock.json
npm install
```

### Сайт не открывается
**Решение:**
1. Убедись, что сервер запущен (видишь `✓ Ready` в терминале)
2. Попробуй другой браузер
3. Попробуй `http://127.0.0.1:3000` вместо `localhost`

### 3D не работает
**Решение:**
- Убедись, что браузер поддерживает WebGL (Chrome, Firefox, Safari — да)
- Попробуй обновить драйверы видеокарты
- Открой консоль браузера (F12) — посмотри ошибки

## 📱 Как открыть на телефоне (в той же Wi-Fi сети)

1. Запусти сервер:
   ```bash
   npm run dev
   ```
2. Узнай IP адрес компьютера:
   - **Windows:** `ipconfig` (ищи IPv4 Address)
   - **Mac/Linux:** `ifconfig` или `ip addr` (ищи inet)
3. На телефоне открой браузер и введи:
   ```
   http://192.168.1.100:3000
   ```
   (замени на свой IP)
